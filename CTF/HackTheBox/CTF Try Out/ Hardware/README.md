# Hardware Security - HTB CTF Try Out

## Overview

This directory contains my complete walkthroughs, notes, concepts, tools, and methodologies for solving the Hardware category challenges from Hack The Box's CTF Try Out.

The purpose of these write-ups is **learning**, not simply recording solutions.

Each challenge focuses on a different aspect of hardware security and embedded systems.
